# 《中英文翻译系统》开发环境

## 1. 项目概述
本项目是一个功能完善的中英文翻译系统，支持文本、图片及文件（Word/PDF）三种形式的翻译输入。系统采用前后端分离架构，结合开源与自训练深度学习模型，提供高效、准确的翻译服务，并通过数据库实现数据管理，同时具备邮件服务能力。


## 2. 开发环境

| 类别         | 具体配置                                  | 说明                                  |
|--------------|-------------------------------------------|---------------------------------------|
| 操作系统     | Linux（推荐 Ubuntu 22.04 LTS 或以上版本） | 提供稳定的开发与运行环境              |
| 编程语言     | Python 3.12                               | 系统核心开发语言，兼容主流深度学习库  |
| 包管理与环境 | Anaconda 3                                | 用于创建独立虚拟环境，管理依赖包      |
| 开发工具     | Jupyter Notebook                          | 便于模型调试、代码片段运行与文档编写  |


### 2.2 前端开发
- **技术栈**：HTML、CSS、JavaScript
- **核心功能**：
  1. 提供简洁直观的用户交互界面
  2. 支持三种输入方式：直接文字输入、图片上传、文件（Word/PDF）上传
  3. 实时展示翻译结果，优化用户视觉体验

- **核心框架与服务**：

## 3. 功能概述
系统支持三种核心翻译场景，整体流程由前端发起请求、后端统一处理、模型执行翻译、结果返回前端构成，具体功能如下：

| 功能模块     | 输入方式                | 处理流程                                  | 输出结果                |
|--------------|-------------------------|-------------------------------------------|-------------------------|
| 文字翻译     | 前端直接输入文本        | 前端提交文本 → 后端接收 → 调用翻译模型 → 返回结果 | 前端展示翻译后的文本    |
| 图片翻译     | 前端上传图片（如截图）  | 前端提交图片 → 后端OCR识别文字 → 调用翻译模型 → 返回结果 | 前端展示识别文字+翻译结果 |
| 文件翻译     | 前端上传Word/PDF文件    | 前端提交文件 → 后端解析文本 → 调用翻译模型 → 返回结果 | 前端展示解析文本+翻译结果 |


## 4. 系统部署与运行步骤
### 步骤1：安装Anaconda并创建虚拟环境
1. 从[Anaconda官网](https://www.anaconda.com/products/distribution)下载并安装Anaconda 3（Linux版本）。
2. 打开终端，创建并激活虚拟环境：
   ```bash
   # 创建虚拟环境（指定Python 3.12）
   conda create -n translation_env python=3.12
   # 激活虚拟环境
   conda activate translation_env
   ```


### 步骤2：安装依赖库
根据模块分组安装所需依赖，可通过`pip`命令逐组安装(若出现环境冲突可以手动调整)：
```bash
# 1. 后端核心依赖（FastAPI、Uvicorn等）
pip install fastapi==0.116.2 fastapi-mail==1.5.0 uvicorn==0.35.0 starlette==0.48.0 pymysql==1.1.2

# 2. 深度学习与模型依赖
pip install torch==2.7.1 transformers==4.55.4 qwen_vl_utils==0.0.11 numpy==1.21.5 tqdm==4.67.1 mindspore==2.7.0

# 3. 文本识别与文件处理依赖
pip install Pillow==11.3.0 PyPDF2==3.0.1 pdfplumber==0.11.0 python-docx==1.2.0

# 4. 可视化与辅助工具
pip install matplotlib==3.10.6 Requests==2.32.5
```


### 步骤3：配置MySQL数据库
1. 安装MySQL（Ubuntu系统示例）：
   ```bash
   sudo apt update
   sudo apt install mysql-server
   ```
2. 启动MySQL服务并设置开机自启：
   ```bash
   sudo systemctl start mysql
   sudo systemctl enable mysql
   ```
3. 登录MySQL，创建项目数据库（如`translation_db`）及所需数据表（如用户表、翻译记录表），并配置数据库用户权限（确保Python通过pymysql可连接）。


### 步骤4：下载和部署模型
1. **开源模型**：通过Hugging Face Hub下载DeepSeek-R1-1.5B、Qwen3-0.6B模型，
    ```bash
    modelscope download --model deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B
    modelscope download --model Qwen/Qwen3-0.6B
    ```
    或使用`transformers`库自动加载：
   ```python
   from transformers import AutoModelForCausalLM, AutoTokenizer
   # 示例：加载Qwen3-0.6B模型
   tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen3-0.6B-Chat")
   model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen3-0.6B-Chat")
   ```
2. **自训练模型**：将基于华为昇腾NPU + MindSpore训练的模型文件部署至指定路径，并在后端代码中配置模型加载路径。


### 步骤5：启动服务与访问
1. **启动FastAPI后端服务**：
   在项目根目录执行命令（假设后端主程序为`main.py`）：
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000
   ```
   - `main:app`：表示`main.py`文件中的`app`实例（FastAPI应用入口）
   - `--host 0.0.0.0`：允许外部设备访问服务
   - `--port 8000`：服务运行端口（可根据需求修改）

2. **访问前端界面**：
   将前端HTML文件部署至Web服务器（如Nginx），或直接在浏览器中打开前端HTML文件，输入后端服务地址（如`http://localhost:8000`），即可完成翻译操作。
