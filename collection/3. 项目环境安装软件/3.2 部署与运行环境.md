## 1.环境要求

### 1.1.硬件推荐配置
| 组件 | 最低配置 | 推荐配置 (用于生产环境) | 说明 |
| :--- | :--- | :--- | :--- |
| **CPU** | 4核心 | 8核心或更高 | 处理模型推理和请求，核心越多并发性能越好 |
| **内存 (RAM)** | 16 GB | 32 GB 或更高 | 大模型加载和运行需要大量内存 |
| **GPU** | 非必需 | NVIDIA GPU (如 V100, A100, 3090) | **显著加速**深度学习模型推理，需配备至少8GB显存 |
| **存储** | 50 GB 可用空间 | 100 GB 可用 SSD 存储 | 用于存放系统、依赖库及大型模型文件 |

### 1.2.软件环境
- **操作系统**: Ubuntu 20.04/22.04 LTS, CentOS 7+, 或 Windows 10/11 (WSL2 推荐用于 Windows)
- **Python**: 3.8, 3.9 或 3.10
- **数据库**: MySQL 5.7 或 8.0
- **包管理器**: `pip` (最新版本)
- **CUDA** (如使用GPU): 11.7 或 11.8 (必须与PyTorch版本匹配)
- **cuDNN** (如使用GPU): 与CUDA对应的版本

## 2.依赖安装

1.  **克隆项目代码**
    ```bash
    git clone <your-repository-url>
    cd wen-shu-translator
    ```

2.  **创建并激活Python虚拟环境**
    ```bash
    # 创建虚拟环境
    python -m venv venv

    # 激活虚拟环境 (Linux/macOS)
    source venv/bin/activate

    # 激活虚拟环境 (Windows PowerShell)
    .\venv\Scripts\activate
    ```

3.  **安装Python依赖包**
    使用项目根目录提供的 `requirements.txt` 文件安装所有必要的Python库。
    ```bash
    pip install -r requirements.txt
    ```
    *如果无法找到此文件，您可以根据项目概述手动安装：*
    ```bash
    pip install fastapi uvicorn pymysql python-multipart python-jose[cryptography] passlib[bcrypt] emails fastapi-mail pillow pymupdf python-docx requests transformers torch torchvision
    ```

4.  **安装PyTorch (特殊处理)**
    上述`requirements.txt`中的`torch`可能不指定版本。为了确保兼容性，**请务必访问 [PyTorch 官方页面](https://pytorch.org/get-started/locally/)** 根据您的CUDA版本选择正确的安装命令。
    *例如，对于 CUDA 11.7：*
    ```bash
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu117
    ```
    *对于仅CPU环境：*
    ```bash
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu
    ```

## 3.数据库配置

1.  **登录MySQL**
    ```bash
    mysql -u root -p
    ```

2.  **执行SQL脚本创建数据库和表**
    将项目文档中的SQL语句保存为一个文件（如 `init_database.sql`），然后执行：
    ```bash
    mysql -u root -p < init_database.sql
    ```
    或者直接在MySQL客户端中逐行执行文档中提供的SQL命令。

3.  **配置环境变量**
    在项目根目录创建 `.env` 文件，并填入您的数据库连接信息和邮件服务配置。
    ```ini
    # Database Configuration
    DB_HOST=localhost
    DB_USER=server
    DB_PASSWORD=server  # 替换为强密码
    DB_NAME=Translator

    # Mail Server Configuration (用于发送验证码)
    MAIL_USERNAME=your_email@gmail.com
    MAIL_PASSWORD=your_app_specific_password  # 注意：使用应用专用密码，而非邮箱密码
    MAIL_FROM=your_email@gmail.com
    MAIL_PORT=465
    MAIL_SERVER=smtp.gmail.com  # 以Gmail为例，请根据您的邮箱提供商修改

    # Model Configuration (如果模型服务在不同机器，需修改localhost)
    MODEL_URI=http://localhost:8000
    ```

## 4.模型准备

系统依赖的模型权重文件**需要手动下载并放置到正确目录**。请根据项目文档指引获取以下模型：

1.  **创建模型目录**
    ```bash
    mkdir -p model/DeepSeek-R1
    mkdir -p model/Qwen3
    mkdir -p model/DotsOCR
    ```

2.  **下载模型权重**
    -   **DeepSeek-R1**: 下载并放置到 `model/DeepSeek-R1/`
    -   **Qwen3-0.6B**: 下载并放置到 `model/Qwen3/`
    -   **OCR 模型**: 下载并放置到 `model/DotsOCR/`

    *注意：模型文件通常很大，下载可能需要较长时间。请确保下载的模型版本与代码兼容。*

## 5.服务部署与运行

### 选项一：一体化启动 (开发模式)
模型服务已集成到主后端中。只需启动FastAPI后端，它将自动处理所有请求（包括调用内置的轻量级模型）。
```bash
# 在项目根目录下运行
uvicorn BackEnd:app --host 0.0.0.0 --port 8000 --reload
```
*参数说明：*
- `--host 0.0.0.0`: 允许任何IP的机器访问此服务。
- `--port 8000`: 指定服务运行在8000端口。
- `--reload`: 代码修改后自动重启服务（仅用于开发）。

### 选项二：启动开源大模型服务 (可选)
如果您需要DeepSeek-R1或通义千问模型的高质量翻译，需要单独启动它们提供的API服务。**这些服务需要先于主后端启动**。

1.  **启动DeepSeek-R1模型服务** (在一个新的终端窗口)
    ```bash
    python Translator_API.py DeepSeek-R1
    ```

2.  **启动通义千问模型服务** (在另一个新的终端窗口)
    ```bash
    python Translator_API.py Qwen3
    ```

3.  **启动主后端服务**
    ```bash
    uvicorn BackEnd:app --host 0.0.0.0 --port 8000
    ```

### 前端配置

1.  **配置API端点**
    编辑 `frontend/js/config.js` 文件，确保 `API_BASE_URL` 指向您正在运行的后端服务地址。
    ```javascript
    // 如果后端运行在本机8000端口
    const API_BASE_URL = 'http://localhost:8000/api';
    // 如果部署在服务器上
    // const API_BASE_URL = 'https://your-server-domain.com/api';
    ```

2.  **使用Web服务器提供服务**
    -   **开发阶段**：可以直接用浏览器打开 `frontend/page-translate.html` 文件。
    -   **生产环境**：推荐使用Nginx等Web服务器来托管前端文件，并配置反向代理到后端API。
        将 `frontend/` 目录下的所有文件放置到您的Web服务器根目录（如 `/var/www/html/`），并参考项目概述中的Nginx配置示例进行设置。

## 6.访问系统

1.  确保所有服务（后端、可选的大模型API）均已成功启动。
2.  打开浏览器，访问您的前端地址：
    -   开发环境: `http://localhost/frontend/page-translate.html` 或 `file:///path/to/project/frontend/page-translate.html`
    -   生产环境: `https://your-domain.com`
3.  注册新账号或使用已有账号登录，开始使用文枢翻译系统。

## 故障排除

-   **`ImportError` 或 `ModuleNotFoundError`**:
    -   确认虚拟环境已激活。
    -   运行 `pip list` 检查所有依赖是否已正确安装。
    -   重新执行 `pip install -r requirements.txt`。

-   **数据库连接错误**:
    -   检查MySQL服务是否正在运行：`systemctl status mysql` (Linux)。
    -   确认 `.env` 文件中的数据库连接参数（主机名、用户名、密码、数据库名）是否正确。
    -   检查用户权限：确保DB_USER有权限访问Translator数据库。

-   **模型加载错误**:
    -   确认模型文件已下载并放在正确的 `model/` 子目录中。
    -   检查日志中的错误信息，确认模型路径是否正确。
    -   确认PyTorch和CUDA/cuDNN版本兼容。

-   **端口占用错误**:
    -   如果8000端口被占用，可以换一个端口启动，例如 `--port 8001`，并记得在前端 `config.js` 中同步修改API地址。

-   **查看日志**:
    -   后端和模型服务的控制台输出是首要的调试信息源，请仔细阅读错误信息。
